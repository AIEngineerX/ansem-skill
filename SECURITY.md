# Security Policy

This skill is read-only knowledge — it never holds keys, signs transactions,
or executes trades. That said, its entire purpose is steering people safely
around a live token, so factual accuracy matters as much as code security
usually does.

## Reporting a problem

If you find:
- A wrong or outdated contract address / mint
- A safety rail that doesn't match reality (e.g. a listed venue that's gone
  bad, a domain that shouldn't be trusted anymore)
- Content that could route someone toward a scam

Please open an issue at
[github.com/AIEngineerX/ansem-skill/issues](https://github.com/AIEngineerX/ansem-skill/issues)
rather than a PR — factual/safety corrections get verified against a primary
source before merging, the same standard the rest of this skill is held to.

## Scope

This repo has no dependencies and executes no code — there's no traditional
vulnerability surface. The main risk is factual: a wrong fact here could cost
someone real money. Treat a correction with the same urgency as a security bug.
